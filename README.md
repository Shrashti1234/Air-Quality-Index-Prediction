# Air Quality Index Prediction using Machine Learning

## Overview
This project predicts Air Quality Index (AQI) using machine learning techniques and provides real-time predictions through a Flask web application.

## Features
- AQI prediction using weather parameters
- Flask-based web application
- Machine Learning model deployment
- User-friendly interface

## Tech Stack
- Python
- Flask
- Scikit-Learn
- NumPy
- HTML/CSS
- Git & GitHub

## Models Evaluated
- Support Vector Regression (SVR)
- Decision Tree Regressor
- XGBoost Regressor
- Extra Trees Regressor

## Run Locally

```bash
pip install -r requirements.txt
python app.py
